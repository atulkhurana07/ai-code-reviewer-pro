# 🚀 AI Code Reviewer Pro (Django)

AI Code Reviewer Pro is a web-based application built using Django that uses AI to analyze code, detect errors, and suggest improvements. It helps developers write clean, optimized, and efficient code with real-time feedback.

---

## 🔥 Features

- AI-powered code analysis  
- Bug and error detection  
- Performance optimization suggestions  
- Clean code recommendations  
- Multi-language support  
- Simple and user-friendly UI  

---

## 🛠️ Tech Stack

- Backend: Django (Python)  
- Frontend: HTML, CSS, JavaScript  
- AI: OpenAI API  
- Database: SQLite
